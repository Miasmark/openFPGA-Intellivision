## Platform files

The platform id is `intv`, the one Spiritualized's Intellivision core
(1.0.2, 2022) installs, so both cores list under one platform.
`dist/Platforms/intv.json` is written for this core with the same four
fields as that core's file (category, name, year, manufacturer; it differs
only in line endings). No platform image (`dist/Platforms/_images/intv.bin`)
is included yet; on a card that already has the other core, its image is
used. `dist/Cores/Miasmark.Intellivision/` has no `icon.bin` yet.

## Notices shipped with releases

`tools/package.sh` puts these in `Cores/Miasmark.Intellivision/licenses/`
in every release zip: this project's `LICENSE`, this file (with MAME's
notice above), analogue-pocket-utils' `LICENSE`, and Analogue's APF
Software License Agreement (`Analogue-APF-Software-License.txt`), copied
