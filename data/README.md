# data

Inputs and outputs of the cartridge CRC table (tools/mapper/README.md). No
game data: only CRCs, sizes, load addresses and flags.

| File | Origin | License |
|---|---|---|
| `mame-hash/intv.xml`, `mame-hash/intvecs.xml` | MAME `hash/`, copied verbatim from the owner's fork at commit 3c6120b6 (files last changed in e2e53f30) | CC0-1.0 (header in each file) |
| `jzintv_name_flags.csv` | rows with the ECS or Intellivoice flag set from jzIntv 20200712 `src/name/name_list.c`, extracted by `tools/mapper/import_name_list.py` (CRC and two flags only) | public domain (Joseph Zbiciak, stated in the file's header and footer) |
| `cart_extra.csv` | ours: images MAME's lists do not give, with the evidence for each map | MIT |
| `cart_table.csv`, `layouts.json` | generated by `tools/gen_crc_table.py`; do not edit | MIT |

`cart_extra.csv` columns: `segments` are `address:words` in file order
(`/pN` for page N of an ECS-style paged range), `ram` is
`address:cells:width`; `status` is `prefix`, `sibling`, `hsi` or `jumps`
(see tools/mapper/README.md); `ref` is the MAME software it relies on.
